# Shopify-Sales-and-Profit-Report-in-Between-01-01-2023-To-18-06-2025
1. Developed an interactive **Shopify Sales and Profit Dashboard** using Excel, SQL, and Python to analyze sales performance from January 2023 to June 2025.

2. Performed **data cleaning, transformation, duplicate removal, and missing value handling** using Python (Pandas and NumPy) to improve data quality and accuracy.

3. Used **SQL queries** to filter and analyze sales transactions, payment methods, and category-wise business performance.

4. Created dynamic **Pivot Tables, Pivot Charts, KPI Cards, and Slicers** in Excel for country-wise, category-wise, and date-wise analysis.

5. Generated actionable insights by analyzing **revenue, profit, product returns, customer locations, and payment method trends** to support data-driven decision-making.
